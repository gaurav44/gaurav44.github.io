# gaurav44.github.io

Personal website and technical blog built with Astro.

## Commands

```bash
pnpm install
pnpm run dev
pnpm run build
pnpm run preview
```

## Project Structure

- `src/pages/` contains routes.
- `src/content/` contains blog posts and content pages.
- `src/components/` contains Astro components.
- `public/` contains static files served from the site root.
